# Інструкція користувача

## Передумови

- Git
- CMake
- Компілятор C++17 (MSVC на Windows)
- `actionlint`

## Запуск агента через `/init`

1. Відкрийте корінь репозиторію у VS Code.
2. Відкрийте Copilot Chat і виберіть режим агента.
3. Уведіть:

   ```text
   /init
   ```

Агент послідовно перевірить Git, підготує файли проєкту, налаштує CMake і тести, створить GitHub Actions workflow та виконає фінальну перевірку. За першої помилки процес зупиниться з поясненням.

## Локальна перевірка

Для незалежної перевірки введіть у Copilot Chat:

```text
/check
```

Команда перевіряє manifest, skills, commands, каталоги `src/`, `tests/`, `docs/`, запускає збірку й CTest, перевіряє, що `build/` не відстежується Git, перевіряє CI YAML і шукає секрети у відстежуваних файлах.

Також скрипт можна запустити без Copilot Chat із кореня репозиторію:

**Windows (Command Prompt):**

```bat
ci.bat
```

**Linux:**

```bash
bash ci.sh
```

**macOS:**

```bash
bash ci.sh
```

Скрипти без параметрів створюють `build/`, конфігурують CMake, збирають Release-конфігурацію та запускають CTest. При помилці будь-якого кроку вони повертають ненульовий код.

## Запуск зібраного `hello`

Після успішного запуску скрипту збірки виконайте команду з кореня репозиторію:

**Windows:**

```bat
build\Release\hello.exe
```

**Linux:**

```bash
./build/hello
```

**macOS:**

```bash
./build/hello
```

Для окремого повторного запуску тестів використовуйте:

```bash
ctest --test-dir build -C Release --output-on-failure
```
