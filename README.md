## Про проєкт

Навчальний проєкт демонструє створення кросплатформного застосунку на C++ із CMake та автоматизованими тестами GoogleTest/CTest. Агент Build Engineer допомагає ідемпотентно підготувати структуру проєкту, налаштувати збірку, тести й GitHub Actions для Windows, Linux і macOS. Проєкт містить виконуваний файл `hello` та тест `BasicAddition`.

## Запуск агента

Відкрийте репозиторій у VS Code, відкрийте Copilot Chat і введіть команду:

```text
/init
```

Команда послідовно запускає підготовку Git (`git-init`), проєкту (`create-project`), збірки й тестів (`create-build`), GitHub Actions (`create-actions`) та підсумкову перевірку (`check`). Окремо перевірити проєкт можна командою `/check`.

## Збірка і тестування

Потрібні CMake і сумісний C++17-компілятор. У корені репозиторію запустіть:

**Windows (Command Prompt):**

```bat
ci.bat
```

**Linux або macOS:**

```bash
bash ci.sh
```

Скрипт конфігурує й збирає проєкт у `build/`, а потім запускає CTest. Будь-яка помилка завершує скрипт із ненульовим кодом. Тести можна запустити окремо:

```bash
ctest --test-dir build -C Release --output-on-failure
```

## Запуск готової програми

Після успішної збірки запустіть виконуваний файл з кореня репозиторію:

**Windows:**

```bat
build\Release\hello.exe
```

**Linux:**

```bash
./build/hello
```

**macOS:**

```bash
./build/hello
```
